# prwrite · our own Premiere project-file library · spec (261112)

**Why.** Diego: "deconstruct the Python script, come up with our own version, improve it with what we've learned, package it so we have our own library unique to what we're doing." The reference is the vendored py-premiere (`../../vendor/py-premiere/`, MIT) and its five section papers (`vendor/py-premiere/papers/`). Rosetta v7 (`plugins/read-premiere-xml-rosetta/`) is the FCP7-xmeml knowledge.

**Scope.** Only what writes a project from a conversation: framing, document, model, parse, build, FCP7 export, CLI. Not captions, .mogrt, masks, color, time remap (those stay in the vendored copy).

**Ours, not copied.** Read the reference for FACTS (element names, attribute names, id/uid rules, element order, gzip framing, the nine objects a new project needs). Then close it and write your own code from this spec. No function may be a paste or a rename of the reference. `ATTRIBUTION.md` credits py-premiere for the schema facts. Stdlib only. Python 3.12 compatible (the Intel Mac). Every module has a docstring that says what goes in and what comes out.

## Layout (package `prwrite`, at `plugins/premiere-project-file-assembly/lib/prwrite/`)

| module | owner | in → out |
|---|---|---|
| `framing.py` | A | bytes ⇄ XML text. Detects gzip vs plain; keeps the gzip header fields Premiere writes; `read_prproj(path) -> str`, `write_prproj(path, text, *, gzip=True)`, size cap on inflate (default 2 GB, raise `FramingError`). |
| `document.py` | A | XML text ⇄ `Doc`: `xml.etree` tree plus an index of `ObjectID`/`ObjectRef`/`ObjectURef`/`ObjectUID` (facts from the reference). `Doc.parse(text)`, `Doc.serialize() -> str` byte-faithful for untouched elements (same indent, same attribute order, same declaration), `Doc.new_id()`, `Doc.find(object_id)`, `Doc.refs_to(object_id)`. |
| `serializer.py` | A | the writer `Doc.serialize` uses: Premiere's formatting (tabs? spaces? find out and state it), empty elements, escaping as Premiere does. |
| `model.py` | B | dataclasses: `Project`, `Bin`, `Media`, `MasterClip`, `Sequence`, `Track`, `TrackItem`, `Rate`, `Time` (ticks: 254016000000 per second: confirm from the reference and say where). Plain data, no XML. Every object has `oid` (the ObjectID in the document) and `uid` when Premiere uses one. |
| `parse.py` | B | `Doc -> Project` (bins tree, master clips, media paths, sequences with tracks and items, timecode start, fps). Unknown things are kept as `extras` so nothing is dropped on round trip. |
| `build.py` | C | `Project -> Doc` mutations: `new_project()` (the minimum objects a fresh project needs, from the reference's facts), `add_bin(parent, name)`, `import_media(path, probe)`, `add_sequence(name, fps, size)`, `place(seq, track, master_clip, at, in_, out)`, `save_version(project, path)` (next `_vNNN`, never overwrite, write `.tmp` then replace). Media facts via `probe.py` (ffprobe if present, else stdlib header readers for mp4/mov/wav/png/jpg). |
| `export_xmeml.py` | D | `Project -> FCP7 xmeml text` for Premiere import, built from Rosetta's print-contract and or-rulings (cite the rule ids in comments). Tier 3 fallback. |
| `cli.py` | D | `python3 -m prwrite inspect|compare|validate|peek FILE` (peek = counts without parsing the whole model). |
| `tests/` | each | stdlib `unittest`, run with `python3 -I -m unittest discover -s lib/prwrite/tests`. Fixtures are MADE by our own `build.new_project()` and by hand-written minimal XML; there is no real .prproj in the repo (say so in the test). Round-trip test: parse(serialize(doc)) == doc text for an untouched document. |

## Shared facts (fill as you learn them; one line each, with the reference file:line)
- Ticks per second: 254016000000 (`vendor/py-premiere/py_premiere/models/time.py:10`); unset time sentinel = -400000 s in ticks (time.py:14). Rates are stored as ticks per frame (`FrameRate`): 29.97 = 8475667200 (time.py:22-23), 23.976 = 10594584000 (our arithmetic). Nominal timecode rate = round(TPS/tpf); drop-frame only for the 30 family, drops nominal//15 numbers per minute (time.py:35-46). [B]
- Root/project/bins [B]: `PremiereData` top-level children are the object table; `<Project ObjectRef>` stub -> Project object -> `RootProjectItem` ref (parsers/project.py:103-112). Panel kinds by tag: RootProjectItem, BinProjectItem, SmartBinProjectItem (reads as a bin), ClipProjectItem (parsers/project.py:18-24). Children: `ProjectItemContainer/Items/Item` refs, smart bin one level down `*/ProjectItemContainer` (models/project_item.py:137-147, parsers/project.py:53-57). Bin name `ProjectItem/Name` (project_item.py:184); a clip's live name is `MasterClip/Name`, `ProjectItem/Name` goes stale (project_item.py:560-569). Node IDs from 1000000 depth-first, stored `ProjectItem/Node/ID` wins (parsers/project.py:82-100).
- Master clip -> media [B]: ClipProjectItem `MasterClip` ObjectURef -> MasterClip `Clips/Clip` ObjectRef -> VideoClip/AudioClip `Clip` core (or `*/Clip`) `Source` ObjectRef -> *MediaSource `MediaSource/Media` ObjectURef -> Media `FilePath`; numeric FilePath = generator, no path (parsers/project.py:27-45, project_item.py:150-158). Source `OriginalDuration` = default out; `SequenceSource/Sequence` ObjectURef marks a sequence clip (parsers/project.py:70-78).
- Sequences [B]: top-level `Sequence` elements (parsers/application.py:43-45), `Name` (models/sequence.py:232). `TrackGroups/TrackGroup` = First (media-type GUID) + `Second` ObjectRef -> VideoTrackGroup | AudioTrackGroup | DataTrackGroup (parsers/sequence.py:73-98, models/sequence.py:688-689). Video group: `TrackGroup/FrameRate` (ticks/frame) and `FrameRect` "l,t,w,h" (parsers/sequence.py:58-84); audio group: FrameRate + `NumAdaptiveChannels` (:85-93). Tracks `TrackGroup/Tracks/Track` ObjectURef -> VideoClipTrack/AudioClipTrack with `ClipTrack/Track/ID`,`Index` (:45-47, :99-101). Items `ClipTrack/ClipItems/TrackItems/TrackItem` ObjectRef; transitions `ClipTrack/TransitionItems/...` (:49-54).
- Track items [B]: `ClipTrackItem/TrackItem/Start|End` (timeline ticks; zero Start is elided) (models/track_item.py:157-176); `ClipTrackItem/SubClip` ObjectRef -> SubClip {`Clip` ObjectRef, `MasterClip` ObjectURef, `Name`} (track.py:266-276, parsers/sequence.py:25-33); source `Clip/InPoint|OutPoint` on the clip object, stored timeline-domain, read = int(raw / PlaybackSpeed) (track_item.py:555-607).
- Timecode start [B]: `Node/Properties/MZ.ZeroPoint` on the Sequence (models/sequence.py:478-486); also MZ.InPoint/OutPoint/WorkInPoint/WorkOutPoint, `MZ.Sequence.VideoTimeDisplayFormat` (sequence.py:72-91, 449). Active sequence = highest `MZ.PrefixKey.OpenSequenceGuidList.N` on the Project bag (parsers/application.py:17-38).
- ObjectID vs ObjectUID [B]: UID (GUID, referenced by ObjectURef): ClipProjectItem, BinProjectItem, MasterClip, Media, Sequence, Video/AudioClipTrack (sequence_builder.py:488-497, 582-602; media_import.py:1276; project_item.py:172). ID (integer, ObjectRef): VideoClip/AudioClip, *MediaSource, *SequenceSource, Video/Audio/DataTrackGroup, *ClipTrackItem, SubClip, component chains (sequence_builder.py:539-575; track.py:270, 358; media_import.py:1311). Identifier attr first, then ClassID, Version (skeleton.py:119-125).
- Root element and version attribute [A]: `<PremiereData Version="3">`; objects are its direct children (`vendor/py-premiere/py_premiere/models/skeleton.py:147`, `vendor/py-premiere/py_premiere/xml/document.py:80-81`). Object elements write the id first, then `ClassID`, then `Version` (`vendor/py-premiere/py_premiere/models/skeleton.py:118-126`, `vendor/py-premiere/py_premiere/xml/document.py:227-230`).
- Object reference attributes [A]: definitions `ObjectID` (integer strings, next = max+1) and `ObjectUID` (GUID); references `ObjectRef` -> ObjectID, `ObjectURef` -> ObjectUID (`vendor/py-premiere/py_premiere/xml/document.py:40-50,98-112,149-168,213-219`; `vendor/py-premiere/py_premiere/models/skeleton.py:148,159`). Duplicates at top level are an error (`document.py:101-102,110-111`). A nested (below top level) element with its own ObjectID/ObjectUID opens a private id scope; refs inside it do not point at top-level objects (`document.py:79-85,113-125,33-39`).
- Gzip header fields Premiere writes [A]: one member, 10-byte header `1f 8b 08 00 00000000 00 0a` = CM deflate, FLG 0 (no FNAME/FCOMMENT/FEXTRA/FHCRC), MTIME 0, XFL 0, OS 10 (older builds 19); body raw deflate level 6; trailer CRC32+ISIZE LE (`vendor/py-premiere/py_premiere/xml/gzip_io.py:3-9,17-19,37-42,95-98`). Plain (non-gzip) XML is read as-is (`gzip_io.py:70-71`; papers/01_framing_and_document.md:52). Reference has no inflate cap (papers/01:8,47).
- Minimum object set for a new project [A noted; C owns]: 9 objects (Premiere writes 40 and rebuilds the rest): a `Project ObjectRef` pointer, Project(1), RootProjectItem(ObjectUID), ProjectSettings(3), ScratchDiskSettings(9), IngestSettings(10), WorkspaceSettings(11), DummyCaptureSettings(16), DefaultSequenceSettings(17) (`vendor/py-premiere/py_premiere/models/skeleton.py:1-13,24-46,147-210`).
- Indent/declaration Premiere writes [A]: `<?xml version="1.0" encoding="UTF-8" ?>` + LF, root, then LF LF (`vendor/py-premiere/py_premiere/xml/serializer.py:24-25`); LF line ends, one TAB per level (`serializer.py:3`, `vendor/py-premiere/py_premiere/xml/mutations.py:16-17`); attributes in insertion order (`serializer.py:61-62`); empty element self-closing only when it is a pure ObjectRef/ObjectURef reference, empty content spelled `<X>` LF tabs `</X>` (`mutations.py:18-19,26-29,39-40`); leaf text escapes `& < >` and CR/LF as `&#13;`/`&#10;`, attrs also `"` and TAB `&#9;` (`serializer.py:22,31-32`); base64 blob leaves end with raw LF+tabs before the close tag (`serializer.py:27-29,48-56`); a payload is stored once, copies are empty elements with the same `BinaryHash` (`vendor/py-premiere/py_premiere/xml/document.py:173-178`).
- Build answers to B [C]: every new sequence gets the full trio ClipProjectItem + MasterClip + Video/AudioSequenceSource (sequence_builder.py:487-547); `place()` takes SOURCE time and stores raw = source*speed (track_item.py:555-588); rates = presets plus any rate whose ticks-per-frame is whole (`build._check_rate`). Media stream facts are real `model.Media` fields now (rate, duration, width, height, audio_channels, sample_rate, has_video, timecode_start); export reads fields first, extras second.
- New-sequence graph [C]: stereo layout = 2 SecondaryContent + 2 ClipChannelSerializer; per audio track one mixer strip (AudioComponentChain, StereoToStereoPanProcessor, AudioFader, AudioMeter, Balance/Volume/Mute AudioComponentParam), then master strip, AudioMixTrack, DefaultPanProcessor, AudioTrackInlet (sequence_builder.py:449-741). Video track IDs 1..n, audio 2.. (:583-608). Audio group FrameRate 5292000 = ticks per 48 kHz sample (:73).
- Movie import graph [C]: VideoStream, AudioStream (MEDIA duration), one Media with AudioStream ref first, VideoMediaSource, Markers, ClipLoggingInfo (no CaptureMode when both streams), VideoClip; with audio AudioMediaSource, SecondaryContent/channel, AudioClip, ClipChannelSerializer/channel, vector, group, master AudioComponentChain (project.py:1215-1349; media_import.py:1084-1623). Channel types {1:0,2:1,6:2} only (media_import.py:93).
- Placement [C]: clone of the master's template clip (fresh ClipID, no InUse, OutPoint then InPoint before ClipID), SubClip, fresh default chain, *ClipTrackItem with Start elided at 0, TrackItems ref before MediaType, a Link object in PersistentGroupContainer/LinkContainer/Links for linked halves, SequenceSource OriginalDuration grows (track.py:266-393,842-937,1221-1275; sequence.py:356-385,604-626; merged_builder.py:441-460).

## Improvements over the reference (what "better" means here)
1. One document index instead of per-call tree walks (speed on 600-clip projects).
2. Byte-faithful serialize for untouched elements so diffs show only our changes.
3. Versions, never overwrite, built into `save_version`.
4. Rosetta rules cited in the xmeml export.
5. Size caps and clear errors instead of silent failure.
6. Plain dataclasses the plugin and the LLM can read as JSON (`Project.to_json()` / `from_json()`).
